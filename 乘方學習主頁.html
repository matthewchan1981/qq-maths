代數第二章 §2.10 有理數的乘方(一)（P44-46）｜ 澳門 S1 代數

必考點考試最愛出的五件事

  • 乘方的意義：n 個相同因數 a 相乘記作 aⁿ，認識底數、指數、冪三個名詞
  • −aⁿ 與 (−a)ⁿ 的分別：−3² = −9，(−3)² = 9——括號決定底數，本章第一大考點
  • 符號規律：負數的冪看指數奇偶：偶次冪為正、奇次冪為負；正數的任何次冪都是正數
  • 分數小數乘方：帶分數先化假分數（−1½ = −3/2）；小數乘方逐位數小數點（0.1⁶ = 0.000001）
  • 乘方應用：細胞分裂 30 分鐘翻倍，5 小時分裂 10 次 → 2¹⁰ = 1024

易錯點這次練習中真實出現的錯誤

  • 8³ = 8×8×8 = 512，不是 128（128 是 8×8×2 的錯覺，三次方要乘三次）
  • 0.1⁶ = 0.000001（每乘一次 0.1 多一位小數，共 6 位），不是 0.1 也不是 0.6
  • (−1.3)⁴ 不能寫成 −1.3⁴——沒有括號，底數就變成 1.3，負號不參與乘方
  • (−1½)³ 要先化假分數 −3/2 再乘方：−27/8 = −3⅜
  • (−2)⁴ = +16，不是 −16——負數的偶次冪是正數，先定符號再算絕對值

難點需要重點突破

  • 負分數乘方：符號與絕對值分開處理，如 (−1½)³ = −(3/2)³ = −27/8
  • 大指數判斷：(−1)²⁰²⁶ = 1、(−1)²⁰²⁵ = −1——不用硬算，看奇偶即可
  • 字母作指數：2a 個 m 相乘 = m²ᵃ，指數可以是代數式

乘方的定義

定義　求幾個相同因數的積的運算，叫做乘方；乘方的結果叫做冪
記法　a·a·a·…·a（n 個，n 為正整數）= aⁿ，讀作「a 的 n 次方」（或 a 的 n 次冪）
三個名詞　aⁿ 中：a 是底數，n 是指數，aⁿ 是冪
特例　3² 讀作「3 的平方」，3³ 讀作「3 的立方」

−aⁿ 與 (−a)ⁿ（本章最關鍵）

−3²　讀作「3 的平方的相反數」= −(3×3) = −9（底數是 3）
(−3)²　讀作「−3 的平方」= (−3)×(−3) = +9（底數是 −3）
口訣　有括號，負號參與乘方；沒括號，負號只在外等候

乘方運算的符號規律

負數的冪　指數是偶數時，冪是正數；指數是奇數時，冪是負數
正數的冪　正數的任何次冪都是正數
計算兩步　① 按奇偶定符號　② 把絕對值乘方
注意　0 的正整數次冪都是 0；帶分數先化假分數再乘方
