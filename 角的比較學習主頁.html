幾何第一章 §1.5 角的比較 ・ 習題七（角平分線）｜ 澳門 S1 幾何

必考點考試最愛出的五件事

  • 比較角大小的兩種方法：度量法（量角器）與重疊法——和比較線段長短完全對應
  • 平角 = 180°：看到「三點共線」或「平角」就要想到拆成兩角相加 180°
  • 角的加減：整體角 = 各部分角之和，如 ∠BOE = ∠AOB − ∠AOE = 130° − 80° = 50°
  • 角平分線定義：從頂點出發、把角分成兩個相等部分的射線
  • 雙角平分線：∠BOD = ∠BOC + ∠COD = ½∠AOC + ½∠COE = 40° + 25° = 65°

易錯點前人踩過的坑

  • 角平分線是射線，不是直線，也不是線段（只有一個端點、向一方無限延伸）
  • 比較角大小看開口大小，不是看邊畫得多長——邊長不影響角的大小
  • 「平角」是一個角（有頂點、有兩邊），不等於一條直線
  • 用 ∠BOE = ∠AOB − ∠AOE 之前，先看圖確認 OE 在角的內部，位置關係錯了全題皆錯
  • 五個等價式任寫一個就能判定角平分線，但要寫對字母順序：∠AOB = 2∠BOC ≠ ∠BOC = 2∠AOB

難點需要重點突破

  • 隱藏角挖掘：圖中沒標的角度，靠「平角 180°」「三角形內角和 180°」推出來（如例2、例3）
  • 雙角平分線組合：兩條平分線各切一半，夾角 = 兩個半角之和
  • 書寫推理過程：每一步都要寫出依據（平角定義／角平分線定義／內角和），考試按步給分

角的比較

度量法　用量角器量出角的度數再比較（如 ∠BOA = 30° < ∠DOC = 58°）
重疊法　把一個角疊到另一個角上，頂點與一邊重合，看另一邊的位置
注意　角的大小只與開口有關，與邊的長短無關

常用角關係

平角　= 180°（三點共線時可拆成兩角之和）
直角　= 90°　　三角形內角和　= 180°
角的加減　若 OE 在 ∠AOB 內部，則 ∠AOB = ∠AOE + ∠EOB

角平分線（五個等價表達式）

定義　從角的頂點出發，把這個角分成兩個相等角的射線，叫做這個角的平分線
若 OC 是 ∠AOB 的平分線，則：
① ∠BOC = ∠COA　　② ∠AOB = 2∠BOC　　③ ∠AOB = 2∠COA
④ ∠BOC = ½∠AOB　　⑤ ∠COA = ½∠AOB
判定　反過來，具備 ①~⑤ 中任何一個式子，就能判定 OC 是 ∠AOB 的角平分線
