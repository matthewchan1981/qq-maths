代數第二章 §2.11 有理數的混合運算（P53-55）｜ 澳門 S1 代數

必考點考試最愛出的五件事

  • 運算順序三條：先乘方 → 再乘除 → 最後加減；同級從左到右；括號先小後中再大
  • 混合計算必考題型：−10+8÷(−2)²−(−4)×(−3) 這種「乘方＋乘除＋加減」綜合題
  • 分數小數混合：先把小數化分數（0.5 = ½），再通分計算
  • 辨析錯誤題：指出同學作業錯在哪（小明作業本型題目，考試常出）
  • 括號有無的對比：2÷(2×3) ≠ 2÷2×3；6÷(−3)² ≠ 6÷(−3²)

易錯點小明作業本的四個經典錯誤（課本 P55）

  • 5÷(−2)×1/2 ≠ 5÷(−1)：乘除同級要從左到右，正確 = 5×(−½)×½ = −5/4
  • 4−(5−2)×1/3 ≠ 4−(5+2)×1/3：去括號不能亂變號，先算括號 3，得 4−1 = 3
  • (−3)×7−(−2)³ ≠ −21−(+8)：(−2)³ = −8，正確 = −21−(−8) = −13
  • 6÷(1/2−1/3) ≠ 6×3−6×2：除法不能分配！正確 = 6÷(1/6) = 36
  • 3+50÷2²×(−1/5)−1 最後一步：2 + (−5/2) = −1/2，不是 1/2——收尾符號要冷靜

難點需要重點突破

  • 多層括號：−1−[1−(1−0.5×4³)] 由內向外一層層剝：4³=64 → 32 → −31 → 32 → −33
  • 乘方混進乘除：8÷(−2)² 要先算 (−2)² = 4，別急著從左到右
  • 長算式不跳步：每行只變一步，符號跟着數走，寫「原式 =」規範格式

混合運算順序法則（課本原話）

法則一　先算乘方運算，再算乘除運算，最後算加減
法則二　同級運算，按照從左到右的順序進行
法則三　如果有括號，應先算小括號裡的，再算中括號裡的，然後算大括號裡的

三級運算分層

第一級　加減運算
第二級　乘除運算
第三級　乘方運算（級別最高，最先算）
口訣　先乘方，再乘除，後加減；同級從左到右；括號小中大

三組「看起來像其實不同」

2÷(2×3) vs 2÷2×3　前者 = 2÷6 = 1/3；後者 = 1×3 = 3。括號改變一切！
2÷(½−2) vs 2÷½−2　前者 = 2÷(−1.5) = −4/3；後者 = 4−2 = 2。完全不同！
6÷(−3)² vs 6÷(−3²)　前者 = 6÷9 = 2/3；後者 = 6÷(−9) = −2/3。括號決定符號！
