幾何第一章 §1.6 角的度量(一)(二) ・ 習題八、九 ｜ 澳門 S1 幾何

必考點考試最愛出的五件事

  • 60 進位制：1° = 60′，1′ = 60″，1° = 3600″（與時間換算完全一樣）
  • 度分秒互化：大化小 ×60，小化大 ÷60（如 3.6° = 3°36′、57°18′ = 57.3°）
  • 度分秒四則運算：加法滿 60 進 1，減法不夠借 1 當 60，乘法逐位乘再進位，除法逐級分
  • 互餘與互補：和為 90° 互餘、和為 180° 互補；∠α 的餘角 = 90°−∠α，補角 = 180°−∠α
  • 角的分類界線：銳角 < 90° < 鈍角 < 180°（平角）；直角 = 90°；周角 = 360°
  • 互餘互補應用題：設某角為 x°，餘角 = 90°−x、補角 = 180°−x，按題意列方程（P10）

易錯點這次練習中真實出現的錯誤

  • 180° − 53°17′ 不是 127°！要借位：179°60′ − 53°17′ = 126°43′（「分」不能丟）
  • 90° − 60°32′ 不是 30°！借位：89°60′ − 60°32′ = 29°28′
  • 加法滿 60′ 要進 1°：48°39′ + 67°21′ = 115°60′ = 116°（不是 115°）
  • 除法要逐級分：46°58′25″÷5，餘 1° 化 60′ 加進去再除，答案 9°23′41″（不能寫 9.2°）
  • 89° 是銳角，不是鈍角！界線：小於 90° 就是銳角
  • 「餘角」「補角」要說清是誰的餘角／補角，不能只說「30° 是餘角」

難點需要重點突破

  • 帶度分秒的互餘互補：先借位再減，例如 ∠α = 60°32′ 的補角 = 180°−60°32′ = 119°28′
  • 度分秒除法：度→分→秒逐級分配，每級的餘數 ×60 併入下一級
  • 餘補性質推理：同角（等角）的餘角相等、補角相等——證明題第一步常用
  • 列方程解角度題：設 x → 寫出餘角/補角表達式 → 列方程 → 代回驗算，四步缺一不可

角的度量單位（60 進位制）

1° 的定義　把一個平角分成 180 等分，每一份就是 1°
基本角　平角 = 180°　直角 = 90°　周角 = 360°（= 2 平角 = 4 直角）
換算　1° = 60′　1′ = 60″　1° = 3600″
1′ = 1/60°　1″ = 1/60′
互化口訣　大單位化小單位 ×60；小單位化大單位 ÷60

度分秒四則運算

加法　度分秒分別加，滿 60″ 進 1′，滿 60′ 進 1°
減法　不夠減就借：借 1° 當 60′，借 1′ 當 60″（90° = 89°60′ = 89°59′60″）
乘法　度分秒分別乘，再按 60 進位整理
除法　從度開始逐級除，餘數 ×60 併入下一級繼續除

互餘・互補・角的分類

互餘　∠1+∠2 = 90°（直角）⇔ 兩角互餘；∠α 的餘角 = 90° − ∠α
互補　∠1+∠2 = 180°（平角）⇔ 兩角互補；∠α 的補角 = 180° − ∠α
性質　同角（等角）的餘角相等；同角（等角）的補角相等
分類界線　銳角 < 90°；直角 = 90°；90° < 鈍角 < 180°；平角 = 180°

互餘互補應用題（列方程）

設未知數　設某角為 x°，則餘角 = 90°−x，補角 = 180°−x
例1　補角是它的 4 倍：180−x = 4x → 5x = 180 → x = 36°
例2 比例題　互餘兩角比 3:7 → 3k+7k = 90 → k = 9 → 兩角 27°、63°
和差題　互補且差 30°：x+y = 180、x−y = 30 → 105° 和 75°
檢查　解出 x 後代回原條件驗算；注意題目問的可能不是 x，而是「它的補角」
