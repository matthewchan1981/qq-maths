代數第二章 §2.10 有理數的乘方(二)・科學記數法（P48-52）｜ 澳門 S1 代數

必考點考試最愛出的五件事

  • (−a)ⁿ 與 −aⁿ 再辨析：(−2)³ 與 −2³ 結果相同（都是 −8），(−2)⁴ 與 −2⁴ 結果不同（16 vs −16）
  • 含絕對值、大指數的乘方：|−5|² = 25、(−1)²⁰²⁴ = 1、0³⁰⁰ = 0
  • 簡便乘方：2²⁰²⁴×(1/2)²⁰²³ = 2（拆一個 2 出來配對）；[(−2)×(−5)]³ = 10³ = 1000
  • 科學記數法：a×10ⁿ，其中 1≤a<10，n = 整數位數 − 1
  • 還原與位數：6×10⁵ = 600000；6.74×10⁵ 的原數是 6 位整數（n+1 位）

易錯點這次練習中真實出現的錯誤

  • −(−3/5)² = −9/25，不是 9/25——括號裡的平方算完，外面還有一個負號！
  • −(−3²/5) = 9/5，不是 9/25——只有 3 被平方，5 不在平方範圍內
  • (x−3)²+|y−4| = 0 → x = 3、y = 4，xʸ = 3⁴ = 81，不是 243（243 = 3⁵，指數看錯）
  • 720000000 = 7.2×10⁸，不是 72×10⁸——a 必須滿足 1≤a<10（只有一位整數）
  • 還原時數錯 0：1.22×10¹¹ = 122000000000（小數點右移 11 位）

難點需要重點突破

  • 拆冪配對簡算：2²⁰²⁴×(1/2)²⁰²³ = 2×(2×1/2)²⁰²³ = 2——大指數不要硬算
  • 平方+絕對值 = 0 型：兩個非負數之和為 0，則各自為 0，分別列方程
  • 負數的科學記數法：−567000000 = −5.67×10⁸，負號照寫，a 取負值 −10<a≤−1

乘方補充法則

10 的冪　10ⁿ = 1 後面 n 個 0；10ⁿ 是 (n+1) 位數。反之，1 後面有多少個 0，10 的冪指數就是多少
非負數性質　任何數的偶次冪 ≥ 0；|a| ≥ 0。若 (x−a)²+|y−b| = 0，則 x = a 且 y = b
拆冪配對　aᵐ×aⁿ 型簡算：把指數拆出相同部分配成 (a×b)ⁿ，如 2×2²⁰²³×(1/2)²⁰²³ = 2×1 = 2

科學記數法

形式　a × 10ⁿ　（n 是正整數）
a 的條件　1 ≤ a < 10（整數數位只有一位）；負數則 −10 < a ≤ −1
n 的確定　大數是大於 10 的整數時，n = 整數位數 − 1
還原　a×10ⁿ 還原：小數點向右移 n 位，不夠補 0

生活數學（乘方應用）

拉麵問題　每捏合一次，麵條根數 ×2：第 n 次後有 2ⁿ 根。拉出 128 根 → 2ⁿ = 128 → n = 7
翻倍付錢　第 1 天 1 毫、第 2 天 2 毫、第 3 天 4 毫……第 20 天 = 2¹⁹ 毫，總和 = 2²⁰−1 毫 ≈ 10486 元——遠超每天 10 元給 20 天的 200 元！
啟示　乘方增長極快（指數爆炸），別被「才 1 毫」騙了
