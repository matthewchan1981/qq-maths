第二章 §2.7 加減混合運算 ・ §2.8 乘法 ・ §2.9 除法 ｜ 澳門 S1 代數

必考點考試最愛出的五件事

  • 減法轉加法：a − b = a + (−b)，之後同號數分別相加（省略括號寫法必用）
  • 乘法兩步走：先定符號（同號得正、異號得負），再把絕對值相乘——順序不能反
  • 倒數三件套：整數（−5→−1/5）、帶分數（1⅔ = 5/3 → 3/5）、0 沒有倒數
  • 湊整簡算：見 25 想 ×4、見 125 想 ×8（如 (−25)×39×(−4) = 3900）
  • 應用題模型：蝸牛爬行、氣溫升降——方向用正負表示，答案要寫「方向＋距離」

易錯點前人踩過的坑

  • a ÷ (b+c) 不能拆！12÷(1/6−½−⅓) 要先通分算括號得 −⅔，答案 −18；硬拆會錯成 12
  • 0 沒有倒數，0 不能做除數（但 0 可以做被除數：0÷(−68) = 0）
  • 乘除同級從左到右：÷(−½)×(−4) 中除號只管緊跟的那一個數
  • 帶分數求倒數／乘除前先化假分數（−1¼ = −5/4）
  • 分配律要乘遍每一項，括號外是負數時符號逐項判斷
  • 題目問「積的符號」就答「正/負」，不要寫完整數值（答非所問會扣分）

難點需要重點突破

  • 除法轉乘法：「除號變乘號、除數變倒數」必須同時進行，只變一半是常見錯法
  • 多負數相乘定符號：先數負因數個數——偶數個→正，奇數個→負
  • 分配律的雙向運用：順用展開、逆用提取公因數（−2×6+3×6 = (−2+3)×6），這是日後合併同類項的根基

加減法則

減法法則　a − b = a + (−b)　（減去一個數 = 加上它的相反數）
省略括號　(−20)+(+3)−(−5)−(+7) = −20+3+5−7，讀作「負二十正三正五負七之和」
加減混合三步　① 減法變加法　② 同號分別相加　③ 按加法法則計算

乘法法則與運算律

乘法法則　兩數相乘，同號得正、異號得負，並把絕對值相乘；任何數 × 0 = 0
多負數相乘　負因數個數為偶數 → 積為正；奇數 → 積為負
交換律　a×b = b×a　　結合律　(a×b)×c = a×(b×c)
分配律　a(b+c) = ab+ac　　逆運算　ab+ac = a(b+c)

倒數與除法

倒數　乘積是 1 的兩個數互為倒數（a 的倒數是 1/a）
陷阱　0 沒有倒數；0 不能做除數；帶分數先化假分數再翻轉
除法法則　a ÷ b = a × 1/b（b ≠ 0）；同號得正、異號得負，絕對值相除
除法分配陷阱　(a+b)÷c = a÷c + b÷c ✓　但 a÷(b+c) ≠ a÷b + a÷c ✗
零的除法　0 ÷ 任何非 0 數 = 0
